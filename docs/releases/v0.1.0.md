# v0.1.0 — U.S. data preparation and baseline models

**Status:** Baseline milestone release. Model tuning, final held-out evaluation, and the recommendation prototype are **not included**.

## Included

- Reproducible U.S.-candidate scope audit and conservative data-preparation workflow, preserved separately from the original broad-cohort analysis.
- U.S.-specific EDA, feature engineering, and experiments comparing feature additions on training data only.
- Six classifiers compared using five-fold stratified cross-validation and fold-fitted preprocessing.
- Automated tests for scope, feature engineering, and target encoding (16 passing in the reviewed version).
- Updated project README and GitHub Actions checks.

## Dataset and evaluation

| Item | Value |
|---|---:|
| Candidate U.S. successful/failed campaigns | 38,420 |
| Training campaigns | 26,945 |
| Reserved test campaigns | 11,475 |
| Training success rate | ~54.61% |
| Best baseline CV ROC-AUC | **0.7235** (HistGradientBoosting) |
| Baseline CV accuracy | **66.84%** (HistGradientBoosting) |
| Baseline CV F1 | **0.7156** (HistGradientBoosting) |

A separate training-only experiment improved Logistic Regression CV ROC-AUC from **0.7199** to **0.7235** using four additional candidates, while HistGradientBoosting changed from **0.7235** to **0.7232**. These are small exploratory differences, not final test improvements.

**All metrics in this release are training cross-validation metrics. The final held-out test set has not been evaluated.**

## Known limitations

- U.S.-candidate labels are inferred from state/DC suffixes in location strings, **not validated country records**.
- The meaning of `funded date`, as well as the historical availability of title and reward values, is still unresolved. Conservative U.S. models exclude those feature families.
- The current prototype does not provide validated recommendations or deployed predictions.
- Findings show historical associations, not causal impacts on campaign success.
